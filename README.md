# DSH 云服务一键隧道

一个 Windows 桌面小工具：**一键建立 SSH 隧道**，把云端服务器上仅监听
`127.0.0.1:3080` 的 DSH（DeepSeek Harness）服务映射到本机，方便随时访问。

## 原理

等价于执行下面这条命令（由程序在后台自动完成）：

```
ssh -N -L 127.0.0.1:3080:127.0.0.1:3080 用户名@服务器IP -p 22 -i 私钥文件
```

- 服务器上的 DSH 服务通常只监听本机 `127.0.0.1:3080`，外部无法直接访问。
- 本工具通过 SSH 建立一条加密隧道，把服务器的 `127.0.0.1:3080` 转发到
  你电脑的 `127.0.0.1:3080`。
- 之后在本机浏览器打开 `http://127.0.0.1:3080` 即可使用 DSH 界面。

## 功能

- 一键启动 / 停止 SSH 隧道
- 多台服务器“配置预设”：保存多份配置，顶部下拉一键切换，无需重填 IP/密钥
- 上传（选择）SSH 私钥并**保存到应用目录**，下次自动记住
- 支持受口令保护的私钥（可勾选“记住口令”）
- 支持密码登录（可选，仅当未使用私钥时）
- 连接测试、一键打开浏览器、日志与状态提示

## 环境要求

- Windows 10 / 11
- Python 3.8+（[官网下载](https://www.python.org/downloads/)，安装时勾选
  “Add python.exe to PATH”）

## 快速开始

1. 双击运行 `run.bat`（首次会自动安装依赖 paramiko）。
2. 填写“服务器地址、SSH 端口、用户名”。
3. 点击“选择并保存私钥”，选择你的 SSH 私钥文件（如 `id_ed25519`）。
4. （可选）填写私钥口令。
5. 点击“**一键启动隧道**”。
6. 状态变为绿色“已连接”后，点击“**打开 DSH 界面**”。

配置和私钥会保存在程序目录下的 `config.json` 与 `keys\` 文件夹中，
下次打开自动加载。

> **多台服务器**：点“新建”为每台服务器各建一个预设，填好各自 IP/端口/用户名/私钥并
> “保存配置”；之后在顶部下拉框一键切换，相关字段会自动回填，无需重新输入。

## 打包成独立 exe（可选）

如果不想在目标电脑上安装 Python，可在本机执行：

```
build_exe.bat
```

生成 `dist\DSH云服务一键隧道.exe`，拷贝到目标电脑双击即可运行，无需 Python。

## 常见问题

**Q1：启动提示“本地端口 3080 已被占用”？**
本机 3080 端口已被其他程序占用。可在“本地端口”改为其它端口（如 3081），
然后用 `http://127.0.0.1:3081` 访问。

**Q2：提示“该私钥受口令保护”？**
请填写正确的“私钥口令”；若希望下次免输入，勾选“记住口令”。

**Q3：连接成功但打不开页面？**
确认服务器上的 DSH 正在运行，且监听 `127.0.0.1:3080`。可在服务器上执行
`ss -tlnp | grep 3080` 或 `netstat -tlnp | grep 3080` 检查。

**Q4：服务器 DSH 监听的是 0.0.0.0:3080，还需要隧道吗？**
可以直接用 `http://服务器IP:3080` 访问，但明文传输不安全；建议仍用本隧道，
或至少在服务器防火墙只开放 SSH 端口。

## 安全说明

- 私钥文件保存在本机程序目录的 `keys\` 下，请勿把整个目录发给他人。
- 私钥口令默认不保存；勾选“记住口令”后以明文写入 `config.json`，请自行权衡。
- 程序对服务器主机密钥采用“首次自动接受”策略（等同 `StrictHostKeyChecking=accept-new`），
  首次连接请确认服务器地址无误。
